# Ashen Crypts

Idle-RPG з автобоєм у темному фентезі. Мобільний PWA на TypeScript без фреймворків.

## Запуск

```bash
npm install
npm run dev                 # розробка, доступна з телефона в тій самій мережі
npm test                    # тести рушія
npm run sim -- 48 60        # бот: 48 годин, перший варіант престижу від +60 уламків
npm run build
```

У режимі розробки (`npm run dev`) працюють прапорці для перегляду вмісту: `?depth=31&wave=10&tutorial=0`, а також `?gallery` (усі спрайти поруч) і `?musictest`.

## Структура

- `src/engine/`: уся логіка без UI. Час передається аргументом, генератор випадкових чисел із зерном.
  - `combat.ts`: бій по хвилях кроками по 0.1 с, навички, рішучість, випробування.
  - `stats.ts`: характеристики героя з рівня, спорядження, мета-покращень і бафів.
  - `loot.ts`: випадіння, автоекіпіровка, скрині з гарантованим епіком кожну 10-ту.
  - `progression.ts`, `ascension.ts`, `daily.ts`, `game.ts`: рівні, престиж, щоденні системи, офлайн.
- `src/ui/`: інтерфейс на DOM; `scene.ts` сцена бою на canvas, `sprites.ts` 5 героїв, 10 ворогів і 5 унікальних босів, `biomes.ts` фони, `music.ts` і `theory.ts` музика.
- `scripts/simulate.ts`: бот для перевірки балансу.

## Цикл утримання

- Герої б'ються самі. Гравець качає їх, розподіляє здобич і може кинути «Бойовий клич».
- Хвилі по 10 на глибину, кожна 10-та хвиля бос зі скринею. Кожні 10 глибин боси мають нову механіку: броньований, регенерація, лють, прикликання, колосальний.
- Директор темпу: після поразки герої отримують «Рішучість» (+12% за поразку, до +100%), яка зникає після перемоги над босом. Після 60 секунд хвилі всі вороги посилюються, тому бій завжди закінчується.
- Спорядження за рідкістю, автоекіпіровка слабкому герою, поліпшення за есенцію зі зайвих предметів.
- Офлайн-фарм до 8 годин (60% ефективності) і скрині за повернення (одна на кожні 2 години, до 4).
- Щоденні випробування: 3 ключі, відновлюються по одному за 6 годин.
- Щоденна серія зі щитами, що заробляються, і три щоденні завдання.
- 19 досягнень, кожне дає +1% сили й золота назавжди.
- Вознесіння з глибини 25: уламки душ для постійних покращень.
- Звук і музика (все синтезується кодом, без файлів): темний ембієнт із акордами Am-F-Dm-E, арпеджіо й серцебиттям, що пришвидшується на босі. Вібрація, експорт та імпорт збереження.
- Анімована сцена бою на canvas: п'ять біомів, п'ять класів героїв і сім типів ворогів із босом намальовані кодом, ефекти навичок, цифри шкоди, монети, струс екрана.
- Відкриття скринь з анімацією, портрети героїв, іконки, навчання для новачка.

Без реальних грошей, лутбоксів і платних таймерів.

## Баланс

Бот, що грає безперервно (`npm run sim -- 120 60`):

| Етап | Час |
|---|---|
| Глибина 10 | ~9 хв |
| Глибина 25 | ~36 хв |
| Глибина 40 | ~2.4 год |
| Перше вознесіння, глибина 49 | ~11 год |

Гравець, що заходить на 10 хвилин (`npx tsx scripts/sessions.ts`, 30 днів):

| Сценарій | День 1 | День 7 | День 30 |
|---|---|---|---|
| 3 заходи на день | глибина 34 | 60 | 84, одне вознесіння на 10-й день |
| 1 захід на день | глибина 11 | 49 | 66, одне вознесіння на 22-й день |

Після глибини ~60 бос із регенерацією стає стіною; кожне вознесіння скорочує шлях до неї.

## Публікація

Збірка не залежить від шляху, тож підходить і для кореня домену, і для GitHub Pages.

- **GitHub Pages:** створи репозиторій, виконай `git remote add origin ... && git push -u origin main`, у Settings → Pages обери Source: GitHub Actions. Workflow `.github/workflows/pages.yml` збере й опублікує.
- **Netlify:** підключи репозиторій (налаштування в `netlify.toml`) або перетягни папку `dist/` після `npm run build`.
- На телефоні відкрий посилання й обери «Додати на головний екран».

Прогрес зберігається в браузері гравця. У Records є експорт і імпорт збереження.
